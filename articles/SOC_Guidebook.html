SOC Guidebook

The SOC (Security Operations Center) Guidebook is a collection of technical field notes exploring foundational concepts, tools, and workflows relevant to security operations. This series documents my exploration of topics that build toward understanding how security analysts monitor, investigate, and respond to activity within an environment. While the articles are organized as a progressive learning series, each is written to serve as a standalone reference for readers interested in a specific topic.

Articles

  1. TCP vs UDP: What Analysts Detect in Network Traffic

    A practical guide to understanding TCP and UDP, recognizing suspicious network traffic, and using protocol behavior to investigate security events.

  2. DNS: Understanding the Protocol Behind Domain Resolution

    Exploring how DNS works, why it matters to security analysts, and how DNS activity can provide insight during investigations.
